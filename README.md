# PyCommand

**Your Personal Productivity Toolkit** – A lightweight custom terminal built in pure Python.

PyCommand is a simple but powerful command-line interface that combines everyday terminal commands with smart productivity tools designed especially for students and developers.

---

## Features

### Smart Productivity Tools
- **`college_setup [folder_name]`**  
  Instantly creates a complete college workspace with folders for Assignments, Notes, Projects, Practicals, and Resources.

- **`duplicate_scan [directory]`**  
  Finds exact duplicate files in a folder (and subfolders) by comparing file size + content.

- **`generate_password <length>`**  
  Generates strong, cryptographically secure passwords (8–128 characters) with uppercase, lowercase, numbers, and symbols.

### Classic Terminal Commands
| Command              | Description                          |
|----------------------|--------------------------------------|
| `ls [directory]`     | List directory contents              |
| `cd <directory>`     | Change current directory             |
| `pwd`                | Show current working directory       |
| `echo <message>`     | Print a message                      |
| `history`            | Show command history                 |
| `clear`              | Clear the screen                     |
| `help`               | Show all available commands          |
| `exit`               | Close the application                |
